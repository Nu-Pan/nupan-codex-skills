# `create_skill.py`

## Summary
- 新しいリポジトリスキルの雛形を、既存ファイルを上書きせず安全に生成するスクリプト。スキル名の検証、一時ディレクトリでの生成、最終配置、生成後の案内を担当する。

## Read this when
- 新しいスキルを追加するための雛形生成処理を変更・確認するとき。
- スキル名の検証、生成先、テンプレート内容、一時生成から配置までの処理を確認するとき。
- CLI の引数、エラー処理、完了メッセージを変更・確認するとき。

## Do not read this when
- 既存スキルの実行時仕様や配布物の内容だけを確認するとき。
- スキル雛形のテンプレート本文を直接変更・確認したいときは、各テンプレート生成関数を直接読む。
- スキル名の妥当性判定だけを確認したいときは、呼び出される検証処理を直接読む。

# `install_skill.py`

## Read this when

- スキル一覧や共通の名前規則を確認するだけのときは、関連するリポジトリ仕様やライブラリを直接読む

# `skill_composition.py`

## Summary
- リポジトリ内のスキル独立性・合成メタデータを検証する共通バリデーター。合成台帳のJSON構造、シナリオ、任意参照、スキル組み合わせ、SPEC.mdの見出し、スキル間参照を検査し、問題をパスとメッセージの組で返す。
- スキル合成台帳やスキル間参照の検証処理を変更・調査する際の実装入口であり、個別スキルの実行仕様やテスト内容を確認する目的では直接の入口ではない。

## Read this when
- リポジトリ全体のスキル合成メタデータの検証規則を変更するとき
- standalone・combination シナリオ、pair、optional reference の妥当性検査を調査するとき
- スキル文書内のパス参照や任意のスキル間参照が検出される仕組みを確認するとき
- 検証結果のエラー条件、並び順、重複検出、ファイル存在確認を確認するとき

## Do not read this when
- 単一スキルの実行時仕様や利用条件だけを確認したいとき
- 検証対象の具体的な台帳データやスキル固有のSPEC.mdの内容を確認したいとき
- リポジトリ共通の追加・開発・テスト手順を確認したいときは、対応する文書を直接読む

# `skill_repository.py`

## Summary
- スキルリポジトリの構造・命名規則・必須ファイル・配布物・README・テキスト・スキル仕様・OpenAI設定・構成定義を検証する共通ヘルパーを提供する。
- 検証結果を対象パスとメッセージを持つ不変データとして表現し、リポジトリ全体または指定スキルの検証を実行する。

## Read this when
- スキルの追加・変更後に、リポジトリ規約や必須ファイル、配布物の妥当性を検証するとき。
- スキル名、SKILL.md の frontmatter、agents/openai.yaml、README.md、未解決プレースホルダーの検証条件を確認するとき。
- スキル構成定義の検証がリポジトリ検証にどう組み込まれているか確認するとき。

## Do not read this when
- 個別スキルの実行時仕様や配布本文を確認したいときは、対象スキルの SPEC.md または配布用文書を直接読む。
- スキル構成の組み合わせ条件だけを確認したいときは、構成定義と専用検証実装を直接読む。
- 検証スクリプトの実行方法だけを確認したいときは、リポジトリの開発・検証手順文書を読む。

# `validate_skills.py`

## Summary
- 指定したスキル、または全スキルについて、共通仕様に基づく構造とメタデータの検証を実行するコマンドライン入口。検証結果を標準出力へ表示し、問題がある場合は失敗終了する。

## Read this when
- スキルの検証方法や検証結果の終了条件を確認したいとき。
- 検証処理のコマンドライン引数と出力の流れを確認したいとき。

## Do not read this when
- スキルの検証ルールそのものを確認したいときは、検証処理を提供するモジュールを直接読む。
- スキル固有の実行時仕様や構造を確認したいときは、対象スキルの仕様書を読む。
