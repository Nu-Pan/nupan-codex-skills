# `adding-a-skill.md`

## Summary
- 新しいスキルを追加するための手順書。目的と適用条件の確定、雛形生成、仕様・配布物・テスト・README・組み合わせ台帳の更新、検証と前向き評価までの流れを扱う。スキル追加作業の実務的な入口となる。

## Read this when
- 新しいスキルを追加するとき
- スキルの仕様、配布物、テスト、README、組み合わせ台帳を整備するとき
- 追加したスキルの構造検証やシナリオ評価の進め方を確認するとき

## Do not read this when
- 既存スキルの実行時仕様だけを確認したいとき
- 共通するリポジトリ構造や保守規則だけを確認したいときは、共通仕様の文書を直接読む
- 開発環境の構築や pytest の一般的な実行規約だけを確認したいときは、開発環境の文書を直接読む

# `development-environment.md`

## Summary
- リポジトリでスキルを開発・検証するための共通環境、テスト配置、pytest 実行方法、完了条件を定める文書。開発環境の構築手順と、単一スキルからリポジトリ全体までの検証入口を提供する。

## Read this when
- スキルの開発環境を構築するとき
- スキル固有またはリポジトリ全体の pytest と検査を実行するとき
- テストの配置・記述規則や完了条件を確認するとき
- スキル変更に伴う合成シナリオの評価方法を確認するとき

## Do not read this when
- スキルの構造や保守方法そのものを確認したいときは、共通仕様の文書を読む
- 特定スキルの実行時挙動を確認したいときは、そのスキルの実行時仕様を直接読む
- 個別スキルの実装やテスト内容を確認したいときは、対象スキルのファイルを直接読む

# `skill-repository-spec.md`

## Summary
- モノレポ内の全スキルに共通する構造、独立性・合成可能性、命名、ファイル責務、配布、インストール、変更手順、検証方法を定義する共通仕様の正本。各スキルのSPEC.mdと重複しないリポジトリ横断規則の入口。

## Read this when
- スキルの追加・削除・変更で、共通構造、配布物、インストール、検証、合成可能性、または変更順序を確認するとき
- 共通規則そのものを変更するとき
- 複数スキルの独立性や組み合わせ評価の扱いを判断するとき

## Do not read this when
- 特定スキルの実行時の機能や振る舞いだけを確認したいときは、そのスキルのSPEC.mdを直接読む
- 利用者向けのリポジトリ概要や共通利用方法だけを確認したいときは、ルートREADME.mdを読む
- 開発環境の構築やpytestの細則だけを確認したいときは、development-environment.mdを読む
