# `SPEC.md`

## Summary
- 正本仕様と実装の適合性を、確認済みの具体的な根拠に基づいてレビューするスキルの実行時仕様。仕様単体の矛盾・表記上の問題と、仕様に対する実装の不整合・明白な致命的問題を区別し、必要な場合だけ修正と再検証まで扱う。

## Read this when
- 正本仕様同士の整合性、実現可能性、文面の誤りや用語統一をレビューするとき。
- 正本仕様と実装の適合性を確認するとき。
- 明示仕様を満たすためのレビュー兼修正や、明白な致命的バグ・旧仕様の残骸を確認するとき。
- 所見の重大度、根拠、重複排除、修正範囲、再検証の扱いを確認するとき。

## Do not read this when
- 明示仕様との適合性を扱わない一般的なコード品質レビューを行うとき。
- 仕様の網羅性向上、好み、流儀、一般的なベストプラクティスだけに基づく改善を検討するとき。
- 利用者から修正を依頼されていない変更を行うとき。
- 未確認の可能性や仕様の隙間を所見として列挙するとき。

# `dist`

## Summary
- 正本仕様と実装・テストの適合性レビュー手順を提供するディレクトリです。レビュー種別、判定基準、根拠の示し方、修正依頼、検証、結果提示を扱い、仕様適合性レビューの実務入口になります。配下の手順書は、正本仕様との照合やレビュー所見の扱いを確認するときに参照します。
- 正本仕様と実装を照合し、仕様の矛盾や実装不整合を根拠付きで判定するエージェント設定を含みます。仕様適合性レビューの実行方針を確認する入口です。

## Read this when
- 正本仕様同士の矛盾や実現可能性、仕様表記の問題をレビューするとき
- 正本仕様に対する実装またはテストの適合性を確認するとき
- レビュー所見の根拠、重大度、重複排除、結果形式を確認するとき
- レビュー所見への修正と検証まで依頼されたとき

## Do not read this when
- 一般的なコード品質、設計改善、命名整理、好みに基づく改善だけを検討するとき
- 正本仕様との関係を確認せず、実装やテストのみを扱うとき
- レビューではなく、別スキルの実行手順やリポジトリ共通規則を確認するとき
- レビュー対象の仕様書と実装ファイルが特定され、直接確認すれば足りるとき
