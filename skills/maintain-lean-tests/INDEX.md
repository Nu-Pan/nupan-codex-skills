# `SPEC.md`

## Summary
- テストと fixture を現行仕様の最小構成に保つためのスキル実行時仕様。適用条件、対象外、入力、独立性と他スキルとの合成、テスト変更・fixture 整理・性能回帰検査・簡潔性・責任範囲に関する規則、出力と完了前の検証条件を定める。maintain-lean-tests の利用判断と詳細な実行手順を確認するための正本仕様。

## Read this when
- テスト、fixture、sample、snapshot、test data の追加・変更・整理・削除を行うとき。
- 重複テストの統合、旧仕様や削除済み実装に対応するテストの整理、実装詳細に依存するテストの見直しを行うとき。
- 性能回帰 test や benchmark の追加・見直し、または他スキルとテスト成果物の責務を合成するとき。
- maintain-lean-tests の実行時規則、出力報告、完了検証の条件を確認するとき。

## Do not read this when
- テストや fixture を変更せず、テストフレームワーク導入手順や品質ゲートだけを決めるとき。
- 正本仕様やプロダクトコードだけを変更するとき。
- 手動確認のみの受け入れ作業、または第三者サービス自体の品質評価を行うとき。
- maintain-lean-tests の適用判断を済ませ、対象リポジトリ固有のテスト方法・配置・ツール設定を直接確認すべきとき。
