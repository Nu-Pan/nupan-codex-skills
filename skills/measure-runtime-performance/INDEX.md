# `README.md`

## Summary
- 実行可能な処理の代表経路を計測し、実測で特定したボトルネックに限定して改善するスキルの概要を示す。変更前後を同一条件で比較し、性能判断と報告を再現可能な計測結果に基づける。必要に応じて最小限の計測 tool を開発依存へ追加する。実行時仕様と配布物への入口を提供する。

## Read this when
- 代表経路の実行性能を計測したいとき
- 計測結果に基づいてボトルネックを改善したいとき
- 変更前後の性能を同じ条件で比較し、再現可能な結果を報告したいとき
- 実行時仕様や配布物の場所を確認したいとき

## Do not read this when
- 性能計測やボトルネック改善が目的ではないとき
- 実行時仕様の詳細を確認する場合は、直接仕様の正本を読むべきとき
- 配布物そのものを扱う場合は、直接配布物の領域へ進むべきとき

# `SPEC.md`

## Summary
- 実行可能な処理経路の実行時間を実測し、baseline と同一条件で比較しながら、実測または profiler に基づくボトルネック改善と再計測を行うスキル仕様。CLI、batch、server、library、test、benchmark などを対象とし、正しさ、安全性、計測条件、未計測範囲の報告まで定める。

## Read this when
- 実行可能な処理経路を新規作成・変更・調査する場合。
- 性能改善、低速化調査、性能回帰確認、benchmark の作成・変更を行う場合。
- baseline の取得方法、代表経路、計測条件、profiler の使用、計測 tool の依存追加方針を確認する場合。
- 性能判断や最終報告に必要な比較条件、反復、ばらつき、正しさ検証、未計測範囲を確認する場合。

## Do not read this when
- 文書、型注釈、静的設定だけを変更し、実行時の処理経路が変わらない場合。
- 性能要件や実行時間に関係しない通常の実装・テスト作業で、別の仕様が直接の読む先である場合。
- CPU 使用量、memory 使用量、throughput だけを扱い、利用者または正本仕様から実行時間の計測を求められていない場合。
- この仕様では扱わない性能要件の新設、本番負荷試験、外部サービスへの無許可の反復 request、または正しさ・安全性・互換性を損なう最適化を行う場合。

# `dist`

## Summary
- 実行時性能の計測・改善を扱うスキルの配布成果物をまとめた入口。代表経路の計測、ボトルネック改善、性能回帰確認の依頼条件を確認するために、配下のスキル本体またはエージェント向けインターフェースへ進む。

## Read this when
- CLI、batch、server endpoint、library、test などの実行時処理について、計測や性能改善のスキルを適用するか判断するとき。
- 代表経路の計測依頼や、計測済みボトルネックの改善依頼の入口を確認するとき。

## Do not read this when
- 文書・型注釈・静的設定のみの変更で、実行時処理経路を変更しないとき。
- 性能ではなく機能の正しさだけを検証するとき。
- 対象リポジトリ固有の benchmark や品質ゲートの手順だけを確認したいとき。
