# japanese-writing-skill

AI が日本語の技術文書を作成または変更するときに使用する Codex スキルです。
読み手が要点と情報の関係を速やかに把握できる文章を作ります。

文章規則の正本は、[`SPEC.md`](SPEC.md) です。
配布物は、[`dist`](dist) にあります。

## 主な文章規則

主な文章規則は、次のとおりです。

- GitHub Flavored Markdown で書く。
- 一文一義にする。
- 見出しと箇条書きで構造化する。
- 要点を詳細より先に置く。
- 三項目以上の列挙では、その列挙が何を示すかを先に述べる。
- 正確性または簡潔さが高まる場合は、技術用語を使う。
