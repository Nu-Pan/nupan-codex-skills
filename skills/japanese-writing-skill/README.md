# japanese-writing-skill

AI が日本語の技術文書を作成または変更するときに使用する Codex スキルです。
読み手が要点と情報の関係を速やかに把握できる文章を作ります。

文章規則の正本は、[`SPEC.md`](SPEC.md) です。
配布物は、[`dist`](dist) にあります。
共通の導入方法は、[ルート README のインストール手順](../../README.md#インストール)を参照してください。

## 適用条件

インストール後は、日本語の技術文書を作成または変更する作業へ暗黙に適用されます。
利用者がスキル名を指定していない場合も使用します。
文書作業が実装や調査などに付随する場合も対象です。

対象となる文章作業を次に示します。

- 新規作成
- 追記
- 改訂
- 推敲
- リライト

対象となる技術文書には、次の文書を含みます。

- 仕様書
- 設計書
- README
- 手順書
- Issue の説明
- Pull Request の説明

`agents/openai.yaml` では、暗黙の呼び出しを明示的に許可しています。

## 主な文章規則

主な文章規則は、次のとおりです。

- GitHub Flavored Markdown で書く。
- 一文一義にする。
- 見出しと箇条書きで構造化する。
- 要点を詳細より先に置く。
- 三項目以上の列挙では、その列挙が何を示すかを先に述べる。
- 正確性または簡潔さが高まる場合は、技術用語を使う。

## 常時適用を確実にする

自動選択に依存せず常時適用する場合は、導入先の `AGENTS.md` に使用条件を追加します。
追加する規則の例を次に示します。

```markdown
## 日本語の技術文書

日本語の技術文書を作成または変更するときは、`$japanese-writing-skill` を使用する。
文書作業が実装や調査などに付随する場合も、この規則を適用する。
```

## 呼び出し例

必要な場合は、プロンプトで `$japanese-writing-skill` を明示的に指定できます。

```text
$japanese-writing-skill を使って、新しい認証要件に合わせて SPEC.md を改訂してください。
```

文章の作成または変更だけを依頼した場合は、既定で完成後の文章だけを返します。
実装や調査などに付随して文書ファイルを変更した場合は、その作業に応じた結果を返します。
