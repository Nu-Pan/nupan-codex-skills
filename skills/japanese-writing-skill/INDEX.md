# `SPEC.md`

## Summary
- 日本語の技術文書を作成・変更する際の文章構成と表現の仕様を定義する正本ドキュメント。適用条件、文書構造、一文一義、要点を詳細より先に置く原則、列挙の扱い、作業手順、出力、確認項目を扱う。スキルの実行規則を確認した後に読む仕様の入口である。

## Read this when
- 日本語の技術文書に関するスキルの適用条件や、SKILL.md に反映すべき規則を確認するとき
- 文章構成・表現の規則の根拠、前提、保護すべき情報、他スキルとの合成条件を確認するとき
- 日本語文書スキルの仕様を変更またはレビューするとき

## Do not read this when
- スキル使用時に従う具体的な手順や出力形式だけを確認したいとき
- 日本語の技術文書そのものを作成・推敲する作業で、実行時規則を直接確認すべきとき
- スキルの配布設定や実行時の指示を確認するだけで、仕様の根拠や保守方針が不要なとき

# `dist`

## Summary
- 日本語の技術文書を作成・変更するための執筆スキル本体。利用者の意図と原文の意味・事実関係を保ちながら、GFM、一文一義、要点先行、適切な列挙と構造化を適用する。
- 日本語技術文書スキルのエージェント向け設定。表示名、概要、既定プロンプト、暗黙的呼び出しの許可を定義する。具体的な執筆規則や内部実装ではなく、スキルの利用条件と呼び出し方法を確認する入口。

## Read this when
- 日本語の仕様書、設計書、README、手順書、Issue、Pull Request説明などを新規作成・追記・改訂・推敲するとき
- 技術文書をGFMで構造化し、要点を先に伝える必要があるとき
- 日本語技術文書スキルの表示、既定の依頼文、暗黙的呼び出しの可否を確認・変更するとき

## Do not read this when
- 日本語の技術文書を作成・変更しない作業のとき
- 文書を変更せず、コードや設定だけを扱うとき
- 英語など日本語以外の文書を扱うとき
- 具体的な執筆手順や品質規則、スキルの内部実装・テストだけを調査・変更するとき
