# `maintain-software-specifications`

- 正本仕様の適用条件、用語、入力の優先順位、他スキルとの合成、変更手順、出力、検証基準を定める実行時仕様を含みます。配布用ディレクトリにはエージェント向けインターフェース定義が含まれます。

## Read this when
- 正本として扱う挙動仕様、設計仕様、インターフェース契約、制約、用語、goal・non-goalを作成または変更するとき。
- 正本仕様と配布物の場所や、正本仕様の変更手順・検証基準を確認するとき。
- 仕様変更時に、関連仕様との優先関係、実装との差異、人間の判断事項と未定義部分の境界を確認するとき。
- このスキルのエージェント向け配布インターフェースを利用または確認するとき。

## Do not read this when
- 正本仕様ではない一般的な技術文書だけを執筆するとき。
- 仕様を変更しない実装またはテストだけを変更するとき。
- 既存実装だけを根拠に、明示されていない正本仕様を復元するとき。
- 正本仕様の具体的な規則や配布物の生成結果だけを確認したいときは、それぞれの本文または配布物を直接読む。

- 配布されるスキル定義、検証 CLI、またはそのテストの入口を判断するとき。

- 検証仕様の詳細は仕様書、実行時の指示はスキル定義、具体的な処理は検証 CLI、挙動の確認はテストへ直接進む。
