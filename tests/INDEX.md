# `test_install_skill.py`

## Summary
- スキル配布物を対象リポジトリへインストールする処理のユニットテスト。単一スキルおよび全スキルの完全コピー、再インストール時の置換、名前順処理、事前検証、失敗時のロールバック、入力検証、必須ファイル検証、CLI の成功出力を検証する。

## Read this when
- スキルインストール処理を変更する場合
- 単一または全スキルのインストール、再インストール、置換失敗時の復元動作を確認する場合
- インストール用 CLI の終了コードや標準出力を変更する場合

## Do not read this when
- スキルの実行時仕様や配布物の内容そのものを確認する場合は、対象スキルの仕様書や配布元ファイルを直接読む
- インストール処理と無関係なスキル機能やテストを調査する場合

# `test_repository_tools.py`

## Summary
- スキルリポジトリの生成・検証ツールを対象にした unittest です。テンプレート構造、命名規則、必須ファイル、README・配布物・メタデータ・合成シナリオの検証結果を確認します。リポジトリツールの変更時に、期待する正常系とエラー報告の境界を確認する入口です。

## Read this when
- スキル雛形の生成処理を変更したとき
- リポジトリ検証処理、README規約、配布用メタデータの検証を変更したとき
- スキル名、必須ファイル、配布ディレクトリ、合成シナリオの検証挙動を確認したいとき

## Do not read this when
- 個別スキルの実行時仕様や配布内容を変更しただけのとき
- リポジトリツールの実装詳細を確認する必要があり、対応する scripts 配下の実装を直接読むべきとき
- テスト対象外のドキュメントやスキル固有ファイルを確認するとき

# `test_skill_composition.py`

## Summary
- スキル間の合成台帳と参照規則を検証するリポジトリテストです。正常系に加え、台帳欠落・重複、単独シナリオやペア分類の欠落、重複関係のシナリオ不備、任意参照とフォールバック、無効なパス参照、仕様見出し不足、対象指定検証時の全体台帳検査を扱います。合成仕様や検証ロジックを変更した際のテスト入口です。

## Read this when
- スキル合成台帳、単独・組み合わせシナリオ、スキル間参照の検証動作を変更または確認するとき
- リポジトリ検証で、合成関係や参照に関するエラーの原因を調査するとき

## Do not read this when
- 単一スキルの実行仕様や配布形式だけを変更するとき
- 合成検証ロジック自体の実装を確認する必要があり、まず検証関数の実装を読むべきとき
